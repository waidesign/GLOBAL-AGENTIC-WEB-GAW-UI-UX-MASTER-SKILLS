# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Global Agentic Web team takes security seriously.

If you discover a security vulnerability within GAW, please do not disclose it publicly in an open GitHub Issue.

Instead, report security vulnerabilities by creating a Private Vulnerability Report on GitHub or by emailing the project maintainers.

Please include:
- A description of the vulnerability and its potential impact
- Detailed steps to reproduce
- Affected files, versions, and environments

We will respond promptly and coordinate a responsible release and patch.
