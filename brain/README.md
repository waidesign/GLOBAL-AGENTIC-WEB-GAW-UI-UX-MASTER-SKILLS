# Global Brain: Default Files

These are the **defaults** GAW ships. On first use, GAW copies them into **your own Global Brain** at `~/.gaw/brain/` (or `$GAW_HOME/brain/`), and from then on reads and writes only your copy. Updating GAW never overwrites your files, and your decisions never end up in GAW's repository.

- See where your brain lives: `gaw brain path`
- Record a decision: `gaw brain update "<category>" "<decision>"`
- Share one brain across machines: set `GAW_HOME` to a synced folder (Dropbox, OneDrive, or a private git repo).

Edit the files here only to change what **new** users start with.
