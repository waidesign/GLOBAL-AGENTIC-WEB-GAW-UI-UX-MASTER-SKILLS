## Interface Direction (only if this project has a user interface)
- **Anti-Slop Discipline**: Reject generic AI aesthetics, random gradients, meaningless card wrappers, and unrequested animations.
- **Visual Pacing**: Deliberate negative space, consistent rhythm, clear visual hierarchy.
- **Typography**: One or two type families with high contrast and a consistent type scale. Body lines under 80 characters; tabular figures for numbers and data tables.
- **Color & Surface**: A palette rooted in the product's domain, semantic tokens (primary, secondary, muted, accent, destructive, background, surface), and WCAG AA contrast (4.5:1 minimum for body text).
