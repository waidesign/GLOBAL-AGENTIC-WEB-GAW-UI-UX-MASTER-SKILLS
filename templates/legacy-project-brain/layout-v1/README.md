## Two layers of memory
- **Project Brain (this folder)**: what is specific to this project. It is shared with your team through git.
  - `context.md`: project goal and stack
  - `rules.md`: rules for this project; these win over everything except your direct request
  - `identity.md`: the project's voice and visual direction
  - `playbook.md`, `project-history.md`: how work is done here, and decisions made
  - `skills.lock.json` + `project-skills.md`: skills chosen for this project (open a skill only when a task needs it)
- **Global Brain (`~/.gaw/brain`)**: your personal preferences and decisions, shared by all your projects. `global-brain.md` here is a generated, read-only summary of it for agents that can't read outside this folder. It is personal, so it is kept out of git. Change your Global Brain, not this file (`gaw brain path`).

Precedence: your request > `rules.md` > Global Brain > skills > tool defaults.

## Active Skills (`active-skills.md`)
When `active-skills.md` is present, it contains specialized instructions generated by `gaw use "<task>" --inject` for the current task. Follow its patterns, copywriting constraints, and performance budgets.
