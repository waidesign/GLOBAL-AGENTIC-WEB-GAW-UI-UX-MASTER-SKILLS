# Project Skill: SEO & Metadata

## Audit Checklist
- [ ] **Title & Description**: Unique `<title>` and `<meta name="description">` on each route.
- [ ] **Canonical URL**: Self-referencing canonical URL on public pages.
- [ ] **Social Graph**: Valid Open Graph (`og:title`, `og:image`, `og:description`) and Twitter Cards.
- [ ] **Structured Data**: Semantic JSON-LD schema markup where applicable.
- [ ] **Robots & Sitemap**: Valid `robots.txt` directives and indexed `sitemap.xml`.
