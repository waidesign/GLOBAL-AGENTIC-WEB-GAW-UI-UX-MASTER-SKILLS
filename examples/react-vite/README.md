# Example React Project Initialized with GAW

This directory illustrates a real React application initialized with the Global Agentic Web:
- **`ai-brain/`**: The local Project Brain containing context, identity, rules, and playbook.
- **`graph.json`, `graph.html`, `GRAPH_REPORT.md`**: Architectural relationship graph generated by Graphify.
- **Agent Instructions**: Multi-agent integration files (`CLAUDE.md`, `.cursorrules`, `AGENTS.md`, `GEMINI.md`, `.github/copilot-instructions.md`).

To test running commands against this project:
```bash
cd examples/react-vite
gaw start
gaw recommend "Add an accessible metrics chart"
```
