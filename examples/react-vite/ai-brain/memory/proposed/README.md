# Proposed memory

Agents write lessons here instead of changing `rules.md`, `context.md` or `playbook.md` themselves. A person reviews each file and either moves the content into the right place or deletes it.

One file per lesson, named `YYYY-MM-DD-topic.md`:

```markdown
# <Topic>

- What happened: <the situation that taught this>
- Proposed: <the rule, convention or note to keep>
- Belongs in: rules.md | context.md | playbook.md | decisions/
```
