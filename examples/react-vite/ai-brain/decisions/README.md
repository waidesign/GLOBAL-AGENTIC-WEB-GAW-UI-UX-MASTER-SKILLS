# Decisions

Short records of choices that shaped this project, so nobody has to guess why later. One file per decision, named `YYYY-MM-DD-short-title.md`.

Keep the recent ones. When there are more than about 20, move the oldest into `archive.md` as one line each (date, decision, status).

## Template

```markdown
# <The decision, in a few words>

- Date: YYYY-MM-DD
- Status: proposed | accepted | replaced by <file>

## What
One or two sentences.

## Why
The problem or constraint that led to it.

## Alternatives considered
- <Option>: why not.
```
